# Bioinformatics Sequence Analyzer
Run:
python -m pip install flask
python app.py
Open http://127.0.0.1:5000

This version includes:
- Animated DNA logo
- Animated DNA background
- Demo FASTA loaded automatically
- Full DNA/RNA/protein analysis
- Nucleotide composition
- GC/AT and GC/AT ratio
- Complement/reverse complement
- ORF and translation
- Amino-acid analysis
- DNA and protein motifs
- 3 plots
- Export report
